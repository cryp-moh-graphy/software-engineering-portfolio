## FlowDraw
A hybrid time/ticket-cap draw trigger with fully on-chain, oracle-free randomness, eliminating per-draw oracle fees entirely while closing the predictability window an attacker would need to front-run the result. O(1) trigger dispatch engine for idempotent financial execution with strict access-controlled state transitions.
